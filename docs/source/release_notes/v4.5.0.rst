Version 4.5.0
=============

Released: July 16th, 2026

This release introduces **GUI replies**: agents can now send rich graphical
user interfaces directly in the chat conversation and react to user
interactions. See the new :doc:`GUI wiki section <../wiki/core/gui>`.

New Features
------------

GUI replies
~~~~~~~~~~~

Agents send a :class:`~baf.core.gui.agent_gui.AgentGUI` as an inline chat
message via
:meth:`~baf.platforms.websocket.websocket_platform.WebSocketPlatform.reply_gui`.
:class:`~baf.core.gui.agent_gui.AgentGUI` wraps a BESSER ``GUIModel`` and adds
an ``id``, a ``persist`` flag for automatic input tracking in
``session.gui_inputs``, and an optional ``width`` for the chat bubble.

GUIEvent and form transitions
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

User interactions with GUI components are dispatched as
:class:`~baf.library.transition.events.base_events.GUIEvent` objects.
:meth:`~baf.core.state.State.when_form_submitted` provides a dedicated
transition that fires on form submissions, with an optional ``form_id`` to
target a specific GUI.

GUI generation with LLMs
~~~~~~~~~~~~~~~~~~~~~~~~~

:func:`~baf.core.gui.gui_llm.create_gui_with_llm` takes a plain-text
description and returns a ready-to-send
:class:`~baf.core.gui.agent_gui.AgentGUI` generated by an LLM. Failed
responses are retried up to ``max_retries`` times (default ``2``).
